## Technical Notes

- All CSS is in one **external** file (`css/style.css`) — no inline or internal CSS
- Navigation menu uses **float: left** on `<li>` elements for horizontal alignment
- Gallery images arranged using **float: left** and **clear: both**
- Contact page uses **float** for two-column layout
- Skill tags use **float: left** for horizontal wrapping
- No JavaScript used
- No CSS frameworks or CDN APIs used
